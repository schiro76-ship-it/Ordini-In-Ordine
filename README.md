# OrdinInOrdine

PWA single-file (HTML/CSS/JS) per la gestione ordini di piccole attività commerciali e artigianali: macellerie, pescherie, panifici, pasticcerie, gelaterie e simili.

Pensata per chi prende ordini ogni giorno al telefono o al banco e ha bisogno di tenerli organizzati senza usare carta o foglietti sparsi — utile soprattutto nei periodi di maggiore richiesta (festività, weekend, eventi locali).

## Cosa fa

- **Ordini**: registra ogni ordine con cliente, articoli, quantità, note e data/orario di ritiro
- **Riepilogo**: vista aggregata di cosa preparare, raggruppato per articolo, per organizzare il lavoro in laboratorio
- **Storico**: archivio degli ordini passati, utile per programmare gli acquisti nei periodi di punta
- **Etichette**: generazione ed export di etichette per ordine, pronte da stampare
- **Multi-dispositivo**: funziona su smartphone, tablet e desktop, con sincronizzazione in tempo reale tra dispositivi

## Stack tecnico

- Frontend: HTML, CSS, JavaScript vanilla — nessun framework, nessuna build
- Backend: Firebase (Firestore per i dati, Authentication per il login)
- Hosting: GitHub Pages

## Stato del progetto

In sviluppo attivo. Nato come strumento interno per una macelleria, in fase di valutazione per la commercializzazione come micro-SaaS ad altre attività artigianali italiane.
